# Feature Proposals

This folder contains feature specifications for proposed additions to Habits.

## Workflow

1. Create a new markdown file for your feature (use `_TEMPLATE.md` as a starting point)
2. Push your feature spec to a branch and open a PR
3. Get the PR reviewed and approved
4. When merged, a GitHub Action will automatically:
   - Analyze your feature spec
   - Generate updates to the core documentation
   - Open a follow-up PR with those updates for review

## Naming Convention

Name your feature file descriptively:
- `phone-reminders.md`
- `multi-user-auth.md`
- `workout-tracking.md`

## What Happens to Merged Features

Once a feature is implemented, its spec remains here as a historical record. The core docs (PROJECT_OVERVIEW.md, ARCHITECTURE.md, etc.) will contain the canonical, up-to-date information.
